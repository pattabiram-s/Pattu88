About

I turn fragile, manual environments into resilient systems teams can trust.

I started out racking servers and answering support calls, and I never lost that operator's instinct. Over 14 years I grew into SRE and DevOps leadership, architecting, migrating, and running production platforms across AWS, Azure, DigitalOcean, and on-premise VMware.

The thread through all of it is reliability: CI/CD pipelines, containerised legacy applications, Kubernetes clusters, and monitoring that surfaces problems before users feel them, with cost, disaster recovery, and security treated as first-class concerns.

Away from the terminal I'm a calm, steady teammate who likes to mentor, keep learning, and leave things better than I found them. I believe good systems create freedom, for the business and for the people running them, and I try to bring that same discipline to how I live and work.

DevOps & SecOps tips

Field notes from building and securing production systems. Short, practical lessons I keep coming back to.

CI/CD

Make pipelines fail fast, loudly

Order jobs by cost and failure rate, cap runtimes, and make the red build name what broke.

Read more → Security

Scope an IAM role to exactly what it uses

Grant nothing by default; scope roles from what the workload actually uses, not guesses.

Read more → IaC

Make Terraform state locked and recoverable

Remote, locked, versioned, encrypted state — and never hand-edited without a backup.

Read more → Reliability

Cover the outages you'll actually have

Alert the boring killers — full disks, expiring certs, bad deploys — and rehearse the rollback.

Read more → Secrets

Get secrets out of images and repos

Keep secrets out of images and git; inject at runtime, scan before merge, rotate on schedule.

Read more → Observability

Instrument to pivot metric → trace → log

Structured logs, RED/USE metrics and a trace id — so you pivot from alert to root cause fast.

Read more → Cost

Pay for what you actually use

Size from real usage, switch off idle non-prod, and tag every resource to an owner.

Read more → Kubernetes

Give every pod requests, limits, and probes

Requests, limits and probes on every pod — four fields that prevent a class of incidents.

Read more → DevSecOps

Catch issues in the PR, enforce at the gate

Scan in the PR where fixes are cheap, and still enforce a hard policy at admission and runtime.

Read more → GitOps

Deliver with GitOps, not kubectl apply

Make git the single source of truth; deploy by merge and let the cluster self-heal drift.

Read more → Supply Chain

Prove your build's provenance (SBOM + SLSA)

Ship images with an SBOM, a signature and verifiable build provenance.

Read more → Threat Detection

Detect runtime threats with eBPF

Catch shells-in-containers and odd syscalls at runtime with eBPF/Falco.

Read more → Zero Trust

Make service-to-service traffic zero-trust

Authenticate and encrypt every service call by workload identity, not network location.

Read more → LLM Security

Defend an LLM app against prompt injection

Stop untrusted text from hijacking your LLM's tools or leaking data.

Read more → LLMOps

Ship LLM features behind evals and guardrails

Ship prompt and model changes behind evals, guardrails and cost budgets.

Read more → AIOps

Cut alert noise with AIOps

Turn a flood of alerts into a few correlated, actionable incidents.
