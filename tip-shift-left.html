Catch issues in the PR, enforce at the gate

Goal: cheap security feedback while coding, plus a hard policy production can’t bypass.

  1. Scan the PR

    Images, IaC and secrets — where a fix is a quick edit.

    trivy fs --scanners vuln,secret,misconfig .
tfsec .            # or: checkov -d .
gitleaks detect --source . --redact

  2. Fail the PR on high severity

    Make the scan a required check.

    trivy fs --severity HIGH,CRITICAL --exit-code 1 .

  3. Sign images on build

    Provenance you can verify later.

    cosign sign --key cosign.key registry/acme/web:1.8.2

  4. Enforce policy at admission

    Block risky things at the cluster door.

    apiVersion: kyverno.io/v1
kind: ClusterPolicy
spec:
  validationFailureAction: Enforce
  rules:
    - name: no-latest
      match: { any: [{ resources: { kinds: [Pod] } }] }
      validate:
        message: "Pin an image tag; :latest is not allowed"
        pattern: { spec: { containers: [{ image: "!*:latest" }] } }

  5. Verify provenance at runtime

    Only run what you signed.

    cosign verify --key cosign.pub registry/acme/web:1.8.2
