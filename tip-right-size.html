Cost

Pay for what you actually use

Goal: right-sized resources, idle non-prod switched off, every cost owned.

  1. Read real usage first

    Size from measured load, not the number that felt safe.

    kubectl top pods -A --sort-by=memory
# EKS: VPA recommend-only; AWS: Compute Optimizer

  2. Right-size requests and instances

    Over-provisioning ‘to be safe’ is the biggest line on most bills.

  3. Switch off non-prod out of hours

    Dev/staging running 24/7 for a 9-to-6 team pays triple.

    # kube-downscaler namespace annotation
downscaler/uptime: "Mon-Fri 08:00-20:00 Asia/Kolkata"

  4. Sweep the quiet waste

    Unattached volumes, idle load balancers, old snapshots.

    aws ec2 describe-volumes --filters Name=status,Values=available \
  --query 'Volumes[].{id:VolumeId,GiB:Size}'

  5. Make the bill accountable

    Tag owner/env/service and enforce it. Untagged spend is unowned spend.
