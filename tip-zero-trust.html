Zero Trust

Make service-to-service traffic zero-trust

Goal: every internal call is mutually authenticated and encrypted, and identity is the workload — not its IP.

  1. Give workloads cryptographic identity

    A mesh (Istio/Linkerd) or SPIRE issues short-lived SPIFFE SVIDs per workload that rotate automatically.

  2. Enforce strict mTLS

    Turn off permissive mode so plaintext is rejected mesh-wide.

    apiVersion: security.istio.io/v1
kind: PeerAuthentication
metadata: { name: default, namespace: istio-system }
spec: { mtls: { mode: STRICT } }

  3. Default-deny, then allow by identity

    Authorize on the caller’s identity, not its network location.

    apiVersion: security.istio.io/v1
kind: AuthorizationPolicy
metadata: { name: payments-allow, namespace: payments }
spec:
  action: ALLOW
  rules:
    - from: [{ source: { principals: ["cluster.local/ns/checkout/sa/web"] } }]

  4. Let identities be short-lived

    SVIDs expire in minutes and rotate — a stolen cert is useless fast.

  5. Verify a call without identity fails

    Curl a service from an unauthorised pod — it should be refused, proving the mesh, not the network, is the control.
