Cut alert noise with AIOps

Goal: fewer, de-duplicated, correlated alerts — each one worth waking someone for.

  1. Normalise alerts into one stream

    Fan every source into a single pipeline (Alertmanager/webhook) with consistent labels: service, severity, cause.

  2. Group, dedupe and silence noise

    Collapse duplicates by cause and suppress during deploys and maintenance windows.

    # Alertmanager
route: { group_by: ['service','alertname'], group_wait: 30s, repeat_interval: 4h }
# silence around a deploy
amtool silence add alertname=~'.*' service=web --duration=20m

  3. Correlate related alerts into one incident

    Tie alerts that share a service, trace or dependency edge into a single incident instead of twenty pages.

  4. Add anomaly detection for the unknowns

    Static thresholds miss slow drifts; a baseline model flags ‘this is abnormal for 3am Tuesday’.

  5. Route with context

    Attach owner, runbook link and recent deploys so the page is actionable, not just a number.
