Secrets

Get secrets out of images and repos

Goal: nothing sensitive in git history or layers; credentials injected at runtime and rotatable.

  1. Block the commit at the source

    A pre-commit hook stops the key before it enters history.

    # .pre-commit-config.yaml
- repo: https://github.com/gitleaks/gitleaks
  rev: v8.18.0
  hooks: [ { id: gitleaks } ]

  2. Scan repo + history in CI

    History is forever and bots index leaks in minutes.

    gitleaks detect --source . --redact

  3. Check the image didn’t bake one in

    A secret in a layer survives ‘deletion’.

    trivy image --scanners secret myimg:latest
docker history --no-trunc myimg:latest

  4. Inject at runtime from a manager

    The app receives a secret; it never ships with one.

    apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
spec:
  refreshInterval: 1h
  secretStoreRef: { name: aws-secrets, kind: ClusterSecretStore }
  target: { name: db-credentials }
  data:
    - secretKey: password
      remoteRef: { key: prod/db, property: password }

  5. Rotate on a schedule; on leak, revoke first

    Automate rotation. If one leaks: kill the live key, then issue a new one.
